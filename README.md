# Evidence-Grounded Counter-Speech Generation (EGCSG)

## Overview

This repository contains the implementation of the proposed Evidence-Grounded Counter-Speech Generation (EGCSG) framework. The framework integrates semantic retrieval from a static knowledge base with real-time web search to generate factually grounded counter-speech responses to online hate speech.

The proposed framework combines FAISS-based document retrieval, Tavily web search, evidence relevance assessment, evidence summarization, and Large Language Model (LLM)-based counter-speech generation.

The repository includes the Python implementation, two input datasets, and the corresponding JSONL outputs generated by the proposed pipeline.

## Datasets

The proposed framework is evaluated using two counter-speech datasets.

### 1. Knowledge-Grounded CONAN Dataset

File: `Original dataset/multitarget_KN_grounded_CN.csv`

This dataset contains the following fields:

- `hate_speech`
- `knowledge_sentence`
- `counter_narrative`
- `target`

### 2. Multi-Target CONAN Dataset

File: `Original dataset/Multitarget-CONAN_unique.csv`

This dataset contains the following fields:

- `hate_speech`
- `counter_narrative`
- `target`
- `version`

## Generated Results

The results directory contains the JSONL outputs produced by executing the EGCSG pipeline on the two datasets.

| Input Dataset | Generated Output |
|---|---|
| `multitarget_KN_grounded_CN.csv` | `EGCSD1.jsonl` |
| `Multitarget-CONAN_unique.csv` | `EGCSD2.jsonl` |

Each JSONL record stores the intermediate retrieval information, generated evidence summary, counter-speech response, and evaluation scores.

The generated results follow the following structure:

```json

      "query": "...",

      "tavily_results": []

  },

    "bert_f1": "...",
    "toxicity": "...",
```

The FAISS retrieval entries include the retrieved document text and its similarity score.

The result files preserve the intermediate and final outputs of the framework, supporting inspection of the retrieval, evidence processing, generation, and evaluation stages.

## Methodology

The proposed framework consists of the following stages:

1. **Static Knowledge Base Construction:** NEWSROOM documents are processed, divided into overlapping text chunks, and converted into dense embeddings using the `all-MiniLM-L6-v2` SentenceTransformer model. FAISS is used to construct the semantic retrieval index.

2. **Query Generation:** Two factual search queries are generated for each hate-speech input using the configured LLM.

3. **Hybrid Evidence Retrieval:** Relevant documents are retrieved from the static FAISS index and real-time web search using Tavily.

4. **Document Relevance Assessment:** Retrieved documents are evaluated for their relevance to the input hate-speech statement.

5. **Evidence Summarization:** Relevant documents are summarized to produce a concise factual context.

6. **Counter-Speech Generation:** The LLM generates a counter-speech response based on the input hate speech and the summarized evidence.

7. **Evaluation:** Generated responses are evaluated using lexical, semantic, factual-accuracy, and toxicity metrics.

## Scripts

| Script | Description |
|---|---|
| `extract_combined_subset.py` | Combines NEWSROOM development, training, and test documents into a static corpus. |
| `build_corpus_improved.py` | Performs document chunking, embedding generation, and FAISS index construction. |

## Installation

Python 3.10 or a compatible version is recommended.

### 1. Clone the repository

```bash
git clone https://github.com/mirzabenny/Evidence-Grounded-Counter-Speech-Generation-EGCSG.git
cd Evidence-Grounded-Counter-Speech-Generation-EGCSG
```

### 2. Activate the Conda environment

Open the project in Visual Studio Code and open its integrated terminal.

Activate the Conda environment:

```bash
conda activate cn
```

If the environment does not exist, create it and activate it:

```bash
conda create -n cn python=3.10
conda activate cn
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up Ollama

Install Ollama and open a separate Windows Command Prompt (CMD).

Pull and run the required model:

```bash
ollama run mistral
```

Keep Ollama running while executing the EGCSG pipeline.

The Ollama model configured in the local environment must match the model used by the scripts.

## Additional Requirements

- Ollama installed and running locally.
- The required Ollama model downloaded.
- Tavily API access for web retrieval.
- Google Perspective API access for toxicity evaluation.
- NEWSROOM dataset files for static knowledge base construction.

## Configuration

Configuration values, including local file paths, model settings, API endpoints, and API keys, should be supplied through a local `.env` file in the repository root.

Users should configure the `.env` file with their own local paths, model settings, and API credentials before executing the scripts.

Do not commit actual API keys or other sensitive credentials to the repository.

## Execution

Run the scripts from the repository root using the activated Conda environment.

### Step 1: Prepare the static corpus

```bash
python scripts/extract_combined_subset.py
```

### Step 2: Build the FAISS index

```bash
python scripts/build_corpus_improved.py
```

### Step 3: Generate counter-speech

After configuring the input dataset and corresponding output file:

For the Knowledge-Grounded CONAN dataset:

```bash
python scripts/counter_speech_generation.py --dataset kn
```

For the Multi-Target CONAN dataset:

```bash
python scripts/counter_speech_generation.py --dataset multitarget
```

### Step 4: Evaluate factual accuracy

```bash
python scripts/LLM_factual_accuracy.py
```

### Step 5: Calculate average evaluation scores

```bash
python scripts/average_scores.py
```

```bash
python scripts/average_factual_accuracy.py
```

## Evaluation Metrics

The framework uses the following evaluation metrics:

- **ROUGE-2:** Measures bigram overlap between generated and reference counter-speech.
- **BLEU-2:** Measures n-gram precision.
- **BERTScore-F1:** Measures semantic similarity using contextual embeddings.
- **Factual Accuracy:** Assesses the factual consistency of generated counter-speech using an LLM-based evaluation approach.
- **Toxicity:** Measures the toxicity of generated responses using the Google Perspective API.

## Reproducibility

The repository provides the implementation scripts, input datasets, and structured JSONL outputs generated by the proposed framework.

The JSONL files retain the retrieval results, generated evidence summaries, counter-speech responses, and evaluation scores for each processed input. This enables researchers to inspect the intermediate pipeline outputs and conduct further analysis.

Reproducing the complete pipeline requires the NEWSROOM corpus, the configured embedding model, FAISS index construction, the selected Ollama model, and access to the required external APIs.
